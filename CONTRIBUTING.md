# Contributing to Permutation-Based Multiple Testing under Dependence

Thank you for your interest in this research software.

This project is currently under active development as part of a PhD research project. Contributions may be considered as the software develops.

## Reporting Issues

When the repository becomes publicly available, users may report bugs or suggest improvements through GitHub Issues.

A useful bug report should include:

- A description of the problem.
- The steps needed to reproduce it.
- The R version and operating system.
- The simulation parameters and random seed.
- Any relevant error messages.

## Suggesting Improvements

Suggestions for improving statistical methods, computational efficiency, documentation, and reproducibility are welcome.

Before implementing substantial changes, contributors are encouraged to discuss the proposed modification with the maintainer.

## Development Workflow

Contributors should create a separate Git branch for their changes and use descriptive commit messages.

Changes should include appropriate documentation and tests.

Where applicable, pull requests should explain the statistical motivation and expected behavior of the proposed changes.

## Testing

Before submitting changes, run:

```bash
Rscript tests/test_permutation.R
```

Changes affecting statistical procedures should include additional tests or simulation checks where appropriate.

## Maintenance

The project is currently maintained by its developer. Maintenance activities include correcting errors, improving documentation, reviewing dependencies, and preserving reproducible research examples.

Long-term support will depend on research needs and available resources.

## Licensing

Contributions must comply with the repository's license and applicable intellectual property requirements.
